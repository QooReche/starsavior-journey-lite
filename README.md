스타세이비어 여정 도우미 경량판

여정 선택지에 마우스를 올리면  
결과(보상, 성공/실패, 난이도별 차이)를 화면 위에 띄워 주는 도구.  
게임 화면을 읽기만 함. 비공식 개인 제작.

[기능]

- 여정 이벤트  
  선택지에 마우스를 올리면 결과(보상, 성공/실패, 난이도별 차이) 표시  
  같은 이름의 아르카나 이벤트는 카드 그림을 보고 해당 아르카나 것만 표시

- 훈련의 방향성  
  선택지마다 나중에 받는 특수 잠재력(AX, CX 등) 계열과 효과 요약 표시  
  구원자별 추천도 같이 표시 (아르카나 편성 화면에서 구원자를 알아본 뒤)

- 일정 (베타)  
  왼쪽 위 날짜에 마우스를 올려야 표시됨  
  이번 턴 일정, 고정 이벤트의 주요 보상, 랜덤 이벤트의 증감 요약 (자동 요약한 참고용)

- 아르카나 편성 화면  
  구원자를 알아보고 추천 카드와 대체 카드를 그림과 함께 표시

[사용법]

1. 압축을 풀고 JourneyHelperLite.exe 실행
2. 게임을 켜면 위쪽에 작은 상단바가 뜸
3. 상단바 왼쪽 클릭은 메뉴, 오른쪽 클릭은 설정
4. 처음에는 데이터를 내려받느라 몇 초 걸릴 수 있음 (인터넷 필요)

[알아 두기]

- 한국어 게임 기준  
  창 모드에서 확인했고 전체 화면은 확인 못 함

- 구원자 추천과 일정은 한국어 게임에서만 동작  
  영어는 일부만 되고 확인 못 함

- 추천과 결과는 참고용이며 틀릴 수 있음

- 서명이 없어서 윈도우나 백신이 경고할 수 있음

- 설정과 기록은 프로그램 폴더 안(data, log)에만 저장됨  
  필요 없으면 폴더째 지우면 됨

- 새 버전은 기존 폴더에 덮어쓰면 설정이 유지됨  
  바뀐 내용은 Releases 페이지의 패치노트에 적음

- 방송이나 녹화에 이 화면도 담고 싶으면 설정창에서 켤 수 있음  
  평소에는 꺼 두기

[문제가 생기면]

설정창 고급·진단 탭에서 진단 정보 복사를 누르고 붙여넣어 알려 주세요.  
게임 화면은 들어가지 않고, 사용자 이름과 경로는 가려짐.

[안내]

- 비영리 팬메이드 도구  
  스튜디오비사이드와 관련 퍼블리셔가 만들거나 승인한 프로그램이 아님  
  제휴·협력 관계 없음

- 게임 관련 권리  
  캐릭터명, 카드명, 아이템명, 이미지 등 게임 관련 지식재산권은 스튜디오비사이드와 정당한 권리자에게 있음  
  정보 제공(선택지 결과 안내) 목적으로만 참고용으로 표시하며 상업적 이익을 얻지 않음

- 동작 방식  
  게임 화면을 읽어 정보를 보여 주는 오버레이 도구  
  게임 파일, 메모리, 서버는 건드리지 않고 입력을 대신 보내지도 않음  
  선택지를 알아보려고 마우스 위치, 클릭, 숫자키 입력 상태를 확인함

- 이용 책임  
  게임 운영정책(이용약관)에 따라 제3자 도구 사용이 제한될 수 있음  
  사용 여부와 그에 따른 책임은 전적으로 사용자 본인에게 있음

- 면책  
  사용으로 생기는 문제(계정 제재, 정보 오류, 손해 등)에 대해 제작자는 책임지지 않음  
  모든 정보는 있는 그대로 제공되며 정확성을 보장하지 않음
