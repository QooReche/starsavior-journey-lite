여정 헬퍼 사용 안내

====================



■ 처음 실행할 때

------------------

JourneyHelper.exe를 처음 실행하면 Windows가 "Windows에서 PC를 보호했습니다" 라는

경고를 띄울 수 있습니다. 이건 이 프로그램이 아직 많이 알려지지 않은 개인 제작 도구라

그런 것이지, 실제로 위험해서가 아닙니다.



    1. 경고창에서 "추가 정보"(More info)를 클릭

    2. "실행"(Run anyway) 버튼을 클릭



일부 백신 프로그램도 비슷한 경고를 띄울 수 있습니다. 이 프로그램은:

  - 화면을 계속 캡처해서 이벤트/선택지를 인식하고

  - 마우스/키보드 입력을 감지해서 선택지를 눌렀는지 확인합니다

이런 동작 특성 때문에 오탐(false positive)이 날 수 있습니다. 걱정되시면 소스코드를

직접 확인하실 수 있습니다: https://github.com/p1021/journeyhelper



처음 켤 때는 OCR 인식 엔진(한글 인식용 AI 모델) 2개를 준비하는 과정이 있어서

수십 초 정도 걸릴 수 있습니다. 화면 위쪽에 "🟡 준비 중..." 배지가 뜨면 정상적으로

진행되고 있는 것이니 조금만 기다려주세요.



https://aka.ms/vs/17/release/vc_redist.x64.exe

"실행이 안 되면 이것부터 설치해보세요"



■ 기본 사용법

------------------

- 여정/아르카나 이벤트 화면에서 선택지에 마우스를 올리면 왼쪽에 예상 보상이 뜹니다.

- 화면 위쪽 상태 배지를 클릭하면 인터페이스를 접을 수 있습니다.

- 선택지를 인식하지 못하거나 문제 발생시 배지를 접었다 펴면 해결될 수 있습니다.

- 배지를 우클릭 시 설정이 가능합니다.



■ 프로그램 종료하기

------------------

배지를 우클릭해 설정창에서 종료 하거나

작업표시줄 오른쪽 아래 트레이 아이콘 영역에 JourneyHelper 아이콘(하늘색 원에"J")를 우클릭해 "종료" 가능합니다.





■ 새 버전이 나왔을 때

------------------

프로그램을 켤 때마다 새 버전이 있는지 자동으로 확인합니다. 새 버전이 있으면 알림창이

뜨고, "예"를 누르면 다운로드 페이지(GitHub)가 브라우저로 열립니다. 자동으로 파일을

바꾸지는 않으니, 새로 받은 압축파일 안의 내용물을 기존 폴더에 덮어써서 교체해주세요.







■ 문제가 생겼을 때

------------------

버그를 발견하시면 챈 댓글이나 GitHub 저장소에 알려주세요:

https://github.com/p1021/journeyhelper





* 본 프로그램(JourneyHelper)은 비영리 목적의 팬메이드(Fan-made) 도구입니다.



이 프로그램은 스튜디오비사이드(Studio Bside)에서 공식적으로 제작하거나 승인한 것이 아니며, 스튜디오비사이드 및 관련 게임 퍼블리셔와 아무런 제휴·협력 관계가 없습니다.

게임 내 캐릭터명, 카드명, 아이템명, 이미지 등 게임과 관련된 모든 지식재산권(IP)은 스튜디오비사이드 및 해당 게임의 정당한 권리자에게 있습니다. 본 프로그램은 이러한 자료를 오직 정보 제공(선택지 결과 안내) 목적으로만 참고용으로 표시할 뿐, 어떠한 상업적 이익도 취하지 않습니다.

본 프로그램은 게임 화면을 읽어 정보를 보여주는 오버레이 도구이며, 게임 클라이언트나 서버에 어떠한 조작도 가하지 않습니다. 다만 게임 운영정책(이용약관)에 따라 제3자 도구 사용이 제한될 수 있으니, 사용 여부와 그에 따른 책임은 전적으로 사용자 본인에게 있습니다.

본 프로그램의 사용으로 인해 발생하는 어떠한 문제(계정 제재, 데이터 오류, 손해 등)에 대해서도 제작자는 책임을 지지 않습니다. 모든 정보는 "있는 그대로(AS-IS)" 제공되며 정확성을 보장하지 않습니다.
